# MLeBooks

大学生 **MorSerO** 根据自身学习情况，利用 AI 编写与整理的个人学习教材与资料。

选题来自学习中遇到的问题与需要，目前涵盖数学基础、竞赛练习、计算机系统、科研方法和强化学习实践。

> **使用声明：不保证这些教材的实用性和准确性。** AI 辅助生成的内容可能存在事实、公式、推导或代码方面的错误与疏漏。请结合课程教材、原始资料和实际实验交叉核对，将其作为学习参考。
